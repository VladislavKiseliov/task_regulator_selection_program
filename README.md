# Помощник конструктора ГПМ

Это настольное приложение для подбора регуляторов давления и поиска схем газораспределительного оборудования на основании заданных параметров. Программа помогает быстро подобрать подходящие регуляторы по входному/выходному давлению и требуемому расходу, а затем найти соответствующие чертежи схем.

## Что делает программа
- рассчитывает/уточняет параметры по введённым данным;
- подбирает подходящие регуляторы по Excel-таблицам;
- учитывает диапазон процента загрузки при подборе;
- формирует имя схемы и ищет файл чертежа по конфигурации оборудования;
- отображает результаты подбора и найденные схемы.

## Архитектура
- GUI (PyQt): ввод данных, запуск расчётов, отображение результатов;
- Controller: связывает интерфейс и бизнес-логику, управляет сценариями;
- Model: расчёты, формирование имени схемы, поиск файлов;
- Utils: вспомогательные функции и работа с Excel.

## Стек
- Python
- PyQt (GUI)
- openpyxl (чтение Excel)

## Основные входные данны
- входное и выходное давление;
- требуемая пропускная спобность (расход);
- диапазон процента загрузки;
- параметры конфигурации газораспределительного оборудования
  (тип изделия, линии, телеметрия, климат, обогрев и т.д.).

## Выходные данны
- список подходящих регуляторов;
- ссылки на найденные схемы (чертежи).

## Файлы данны
- Excel-файлы с характеристиками регуляторов: `*.xlsx`
- каталог со схемами: папка `Каталог/` (структура по типу изделия и модели)

## Запус
Приложение запускается как GUI. Обычно:
1) открыть/запустить основной скрипт приложения;
2) заполнить параметры в интерфейсе;
3) нажать «Подобрать регулятор» и, при необходимости, «Подобрать схему».

## Примечание
Формат Excel-таблиц и структура папки со схемами должны соответствовать текущему алгоритму подбора и формирования имён файлов.
