# Помощник конструктора ГПМ

Настольное приложение (PyQt5) для подбора регуляторов давления и поиска схем
газораспределительного оборудования по заданным параметрам. Помогает быстро
подобрать подходящие регуляторы по входному/выходному давлению и требуемому
расходу, а затем найти соответствующие чертежи схем (.cdw).

## Быстрый старт
Готовую версию запускают из собранной папки (без установки Python):

1. Распакуйте/откройте папку сборки — по умолчанию это `build/exe.win-amd64-3.13/`.
2. Запустите `RegulatorSelector.exe` двойным кликом.
3. В окне приложения добавьте нужный `.xlsx` (перетащите в зону сброса либо введите
   путь к обрабатываемым файлам), задайте входное/выходное давление и пропускную
   способность, затем нажмите «Подобрать регулятор».

> Не вытаскивайте `.exe` из папки сборки отдельно — рядом должны оставаться
> папки `src/` и `Каталог/` (логика и схемы), иначе приложение не запустится
> или не найдёт чертежи.

## Установка (для разработки)
```bash
# создать виртуальное окружение
python -m venv .venv
# активировать (Windows PowerShell)
.\.venv\Scripts\Activate.ps1
# установить зависимости
pip install -r requirements.txt
```

## Возможности
- расчёт и уточнение инженерных параметров (диаметр газопровода / скорость газа);
- подбор подходящих регуляторов по Excel-таблицам (`.xlsx`);
- учёт диапазона процента загрузки при подборе;
- автоматический подбор ближайших доступных давлений, если точного
  совпадения в таблицах нет;
- формирование номенклатурного имени изделия и поиск файла чертежа по
  конфигурации оборудования;
- обновление результатов поиска и найденных схем;
- кэширование разобранных книг и результатов подбора (повторный подбор
  практически мгновенный);
- тяжёлые операции (анализ файлов, поиск схем) выполняются в фоновом потоке —
  интерфейс не замерзает.

## Архитектура
- `src/GUI/` — PyQt-интерфейс (окно + генератор `mainwindow.ui`), применяет
  единую тему (`style.py`);
- `src/controller.py` — контроллер: связывает интерфейс и бизнес-логику,
  управляет сценариями и фоновыми задачами;
- `src/core/` — чистое ядро без зависимости от PyQt:
  - `regulator_selector.py` — алгоритм подбора регуляторов;
  - `nearest_values.py` — подбор ближайших давлений;
  - `scheme_finder.py` — формирование имени схемы и поиск файла;
  - `calculator.py` — инженерные расчёты;
  - `workbook.py` — быстрый загрузчик Excel (pandas/openpyxl) с кэшем;
  - `cache.py` — LRU-кэш книг и результатов;
  - `parsing.py` — устойчивый разбор «грязных» ячеек;
  - `models.py` — доменные модели;
- `src/utils/` — вспомогательные модули (регистр колбэков, фоновый поток).

## Стек
- Python 3.13
- PyQt5 (GUI)
- openpyxl (чтение Excel, используется в сборке `.exe`)
- pandas (опционально, только для разработки/тестов — в `.exe` не входит)
- cx_Freeze (сборка в `.exe`)

## Входные данные
- входное и выходное давление (МПа);
- требуемая пропускная способность (м³/ч);
- диапазон процента загрузки;
- параметры конфигурации газораспределительного оборудования
  (тип изделия, линии, телеметрия, климат, обогрев и т.д.).

## Выходные данные
- список подходящих регуляторов (карточки с процентом загрузки);
- ссылки на найденные схемы (чертежи `.cdw`).

## Файлы данных
- Excel-файлы с характеристиками регуляторов: `*.xlsx` в корне проекта;
- каталог со схемами: папка `Каталог/` (структура по типу изделия и модели).

## Запуск (в режиме разработчика)
```bash
python selRegulator.py
```

## Сборка в `.exe`
```bash
python setup.py build_exe
```
Результат — в `build/exe.win-amd64-3.13/` (или аналогичной папке cx_Freeze):
`RegulatorSelector.exe`, рядом с ней — `src/`, `Каталог/`, `icon.ico`,
`instruction.txt`.

> Сборка **не включает** pandas/numpy/scipy — чтение Excel выполняется
> openpyxl (read_only, с кэшем), поэтому `.exe` остаётся компактным
> (~120 МБ). Это сделано намеренно в `src/core/workbook.py`: pandas
> подгружается лениво и нужен только при разработке/тестах.

## Тесты
```bash
python -m unittest discover -s test -p "test_*.py"
```

## Примечание
Формат Excel-таблиц и структура папки со схемами должны соответствовать
текущему алгоритму подбора и формирования имён файлов.

## Автор и лицензия
Проект ведётся как внутренний инженерный инструмент. Связаться / получить
ветку со свежими наработками можно через репозиторий:
`https://github.com/VladislavKiseliov/task_regulator_selection_program`.

Данные (Excel-характеристики регуляторов и чертежи `.cdw` в `Каталог/`)
предоставлены разработчиком — при распространении учитывайте их происхождение.
